# Expo Group Task App

一个基于 Expo Go 的群组任务管理应用，支持文档任务、投票任务和讨论任务。

## 功能特性

### 用户认证
- ✅ 用户登录（邮箱密码，毛玻璃设计）
- ✅ 用户注册（用户名、邮箱、密码、验证码）
- ✅ 修改密码（邮箱验证码验证）

### 主仪表板
- ✅ 顶部导航栏（首页、筛选、消息、设置）
- ✅ 左侧边栏（群组列表、搜索、筛选）
- ✅ 主内容区（首页、群组详情、消息中心、设置页面）

### 群组管理
- ✅ 创建群组
- ✅ 群组列表（支持筛选：所有群组/我创建的/我管理的/我参与的）
- ✅ 群组详情（查看任务、成员、完成度）
- ✅ 成员管理（邀请成员、查看成员列表、角色管理）
- ✅ 权限控制（群主/管理员/普通成员）

### 任务系统
- ✅ 文档任务（上传文档、下载、提交完成）
- ✅ 投票任务（创建投票选项、参与投票、查看结果统计）
- ✅ 讨论任务（创建讨论主题、发表评论和回复）

### 消息中心
- ✅ 群组邀请（接收、查看、接受/拒绝）
- ✅ 邀请状态（待处理、已接受、已拒绝）

### 个人设置
- ✅ 个人信息（查看/修改用户名、邮箱）
- ✅ 语言设置（中英文切换）
- ✅ 退出登录（清除缓存并返回登录页）

### 其他功能
- ✅ 自动刷新（每5分钟自动刷新数据）
- ✅ 缓存管理（使用 AsyncStorage 缓存用户数据和任务）
- ✅ 响应式设计（适配移动端）
- ✅ 搜索功能（模糊搜索群组名称）
- ✅ 进度条可视化（任务完成度动画显示）

## 安装和运行

### 前置要求
- Node.js (推荐 16.x 或更高版本)
- npm 或 yarn
- Expo CLI
- Expo Go 应用（在手机上安装）

### 安装步骤

1. 安装依赖
```bash
npm install --legacy-peer-deps
```

**注意**：由于依赖版本冲突，必须使用 `--legacy-peer-deps` 标志。

2. 启动开发服务器
```bash
npm start
```

3. 在手机上打开 Expo Go 应用，扫描终端显示的二维码

### 使用说明

1. **注册账号**
   - 点击"注册"链接
   - 输入用户名、邮箱、密码（至少6位）
   - 点击"获取验证码"（验证码会以弹窗形式显示）
   - 输入验证码并提交

2. **登录**
   - 使用注册的邮箱和密码登录

3. **创建群组**
   - 在首页点击"创建群组"
   - 输入群组名称和描述
   - 提交创建

4. **管理群组**
   - 点击群组进入详情页
   - 可以邀请成员、创建任务、管理成员

5. **创建任务**
   - 在群组详情页的"任务"标签下
   - 点击"创建任务"
   - 选择任务类型（文档/投票/讨论）
   - 填写任务信息并提交

6. **查看消息**
   - 点击顶部导航的"消息"
   - 查看群组邀请
   - 接受或拒绝邀请

7. **设置**
   - 点击顶部导航的"设置"
   - 可以修改个人信息、切换语言、退出登录

## 数据存储

由于目前没有后端，所有数据都存储在本地 AsyncStorage 中：
- 用户数据
- 群组数据
- 任务数据
- 邀请数据

**注意**：应用进入后台时会自动清除所有数据，这是为了模拟"关闭应用后删除"的需求。

## 注意事项

1. 验证码功能是模拟的，实际应用中应该从服务器获取
2. 密码存储未加密，实际应用中应该使用加密存储
3. 文件上传功能使用本地 URI，实际应用中应该上传到服务器
4. 应用进入后台时会清除所有数据，这是按需求实现的
